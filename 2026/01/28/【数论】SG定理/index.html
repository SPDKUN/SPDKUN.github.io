【数论】SG定理

2026-01-28
未分类
2.6k 词
  • 数论

解决二人博弈问题的通解就是SG定理，回顾博弈游戏，不难发现：

  • 由必败态通过一步操作得到的一定是必胜态
  • 由必胜态通过一步操作得到的可能是必胜态，也可能是必败态，聪明的操作是将必败态转移给对手。

从二维Nim游戏开始研究：

  • 两个必败态的组合一定是必败的。先手只能将其中之一变为必胜态，但是聪明的后手可以将这个必胜态变为必败态转移给先手。
  • 一胜一败的组合是必胜的。先手可以一直将必胜态转化为必败态，而后手总是面临两个必败态。
  • 两个必胜态的组合是最复杂的，肯能是必胜也可能是必败。聪明的操作是不能将必胜态变为必败态，因为那样会给对手一胜一败的必胜局面。所以两人得一直将必胜态转移到必胜态，直到无法转换为必胜态的一方就输了。

通过以上例子，做如下定义：

根据定义来设计一个函数SG，SG(X)表示X是第几级必胜点：

$$
SG(X) = MEX{SG(y)|x->y}
$$
 $MEX$是一个定义在集合上的函数，表示不属于集合的最小非负整数。这个函数通俗来讲就是将点x能一步走到的点y的SG值都放在一个集合中，再对这个集合求最小非负整数。假设这个最小非负整数为n，说明x可以走到0~(n - 1)级必胜点，x为n级必胜点。

由此我们可以得到SG定理：

  • 同级必胜点（SG相同）组成的游戏比败。先手只能降低其中一个必胜点的等级，而后手可以相应降低另外一个。最后先手会面临两个1级必胜点，只能将其中一个变为必败态。
  • 不同级必胜点（SG不同）组成的游戏比胜。先手可以将两个必胜点的等级变为相同送给后手，此时后手就面临同级必胜点组成的游戏了。

在计算上通过异或来判断SG值是否相等。子游戏的SG异或和为0说明母游戏必败，反之必胜。

Grundy’s Game

题目描述

There is a heap of n coins and two players who move alternately. On each move, a player chooses a heap and divides into two nonempty heaps that have a different number of coins. The player who makes the last move wins the game.
Your task is to find out who wins if both players play optimally.

输入

The first input line contains an integer t: the number of tests.
After this, there are t lines that describe the tests. Each line has an integer n: the number of coins in the initial heap.
Constraints
1 ≤ t ≤ 105
1 ≤ n ≤ 106

输出

For each test case, print “first” if the first player wins the game and “second” if the second player wins the game.

题目大意：

分一个石子数量为n的石堆，每次可以将石堆分为不等的两份，最后不能分的人输。

解题思路：

分析过后得1和2为必败态，3能一步到1和2，说明3是由两个必败态组合起来的必胜态，为1级必胜点。此时3的唯一后继状态为(1, 2)。而(1, 2)由两个子游戏1和2组成，这个状态的SG值为1和2的异或和，即$0\ xor\ 0 = 0$，而3的SG是不属于它所有后继状态中的最小非负整数，由于后继状态中只有0，所以3的SG为1.

通过以上的思路可以一直分析下去，大概到2000+时会发现后面的都是必胜态了。
