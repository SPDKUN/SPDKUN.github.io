【数论】伯恩赛德引理

2026-01-22
未分类
2.6k 词

伯恩赛德引理用于解决旋转对称性去重的组合问题，具体例子见下题：

Counting Necklaces

题目描述

Your task is to count the number of different necklaces that consist of n pearls and each pearl has m possible colors.
Two necklaces are considered to be different if it is not possible to rotate one of them so that they look the same.

输入

The only input line has two numbers n and m: the number of pearls and colors.
Constraints
1 ≤ n,m ≤ 10^6

输出

Print one integer: the number of different necklaces modulo 10^9+7.

样例输入

样例输出

题目大意：

有一串n个珠子的项链，每个珠子可以从m个颜色中选择一个，问有多少种颜色搭配。

解题思路：

因为项链是环形可以旋转，因此不能直接$m^n$，根据伯恩赛德引理：不同轨道（等价类）的数量等于各个置换下不变元素数量的平均值。

不同的旋转长度是不同的轨道，这里定义为群G是所有n个旋转（旋转 0, 1, 2, …, n-1 位）。对于每个旋转长度k（表示旋转了k位），有：

  • 它将项链分成了 $gcd⁡(n,k)$ 个循环
  • 每个循环的长度为 $n/gcd⁡(n,k)$
  • 要使项链在旋转 k 位后不变，每个循环内的珠子必须颜色相同
  • 因此，对于每个循环，可以独立选择颜色，所以有 $m^{gcd⁡(n,k)}$种不变项链

因此不同项链数为：
$$
\frac{1}{n}∑_{k=0}^{n-1}m^{gcd(n,k)}
$$

Counting Grids

题目描述

Your task is to count the number of different n*n grids whose each square is black or white.
Two grids are considered to be different if it is not possible to rotate one of them so that they look the same.

输入

The only input line has an integer n: the size of the grid.
Constraints
1 ≤ n ≤ 10^9

输出

Print one integer: the number of grids modulo 10^9+7.

样例输入

样例输出

题目大意：

有一个n* n的网格，每个格子可以填黑白两色，通过任意旋转都不相同的两种网格才视为不一样，问有多少种填色方法。

解题思路：

一共四个旋转群（0，90，180，270），方法数为
$$
\frac{1}{4}∑2^{循环数x_i}
$$

旋转0度：不用旋转，循环数为$n^2$。

旋转90/270度：

n为偶数时 以2为例 循环数
1 2 -> 4 1 $n^2/4$
4 3 -> 3 2
n为奇数时 以3为例
1 2 3 7 4 1
4 5 6 -> 8 5 2 $1 + (n^2 - 1)/4$
7 8 9 9 6 3

旋转180度：

n为偶数时 以2为例 循环数
1 2 -> 3 4 $n^2/2$
4 3 -> 2 1
n为奇数时 以3为例
1 2 3 9 8 7
4 5 6 -> 6 5 4 $1 + (n^2 - 1)/2$
7 8 9 3 2 1

Code：


```#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll mod = 1e9 + 7;

ll fastpower(ll base, ll k){
  ll ans = 1;
  while(k){
    if (k & 1) ans = ans * base % mod;
    base = base * base % mod;
    k >>= 1;
  }
  return ans;
}

int main(){
  ios::sync_with_stdio(false);
  cin.tie(0), cout.tie(0);
  ll n, inv4 = fastpower(4, mod - 2);
  cin >> n;
  ll x0 = n * n;
  ll x1;
  if (n & 1) x1 = (n * n + 3) / 4;
  else x1 = n * n / 4;
  ll x2;
  if (n & 1) x2 = (n * n + 1) / 2;//注意循环数不能取模，取模了快速幂就算不对了
  else x2 = n * n / 2;
  ll ans = 0;
  ans = (ans + fastpower(2, x0)) % mod;
  ans = (ans + fastpower(2, x1)) % mod;
  ans = (ans + fastpower(2, x2)) % mod;
  ans = (ans + fastpower(2, x1)) % mod;
  ans = ans * inv4 % mod;
  cout << ans << "\n";
  return 0;
}
